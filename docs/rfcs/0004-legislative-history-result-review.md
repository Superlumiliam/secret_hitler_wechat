# RFC-0004：结果页立法牌面复盘

## 目标

在终局结果页公开每轮总统弃掉的政策、总理弃掉的政策和总理颁布的政策，帮助线下玩家复盘立法过程，同时不泄露进行中的隐藏牌面。

## 方案

- `game_core` 初始化 `legislativeHistory: []`。
- 总统弃牌时追加一条最小记录：`round`、总统和总理成员 ID、总统弃牌；总理正常颁布时补写总理颁布牌和总理弃牌。
- 总理提出否决或总统拒绝否决不改记录；总统同意否决时补写总理两张弃牌，颁布牌为 `null`。
- 所有记录与对应游戏状态、事件和快照迁移在同一事务中写入；命令幂等重试不得重复记录。
- 结果快照只返回上述原始记录；进行中的公共快照不返回该字段。旧对局缺少记录时返回空数组。
- 前端将记录整合进关键时间线的对应轮次，映射为“弃掉/颁布”文案，不单独渲染复盘板块，也不展示或推导任何“看到的牌”字段。

## 边界与兼容性

不新增 action、命令或错误码。`ResultSnapshot` 增加可选 `legislativeHistory` 字段；旧客户端忽略该字段，旧对局返回空数组。记录中的政策值沿用 `LIBERAL`、`FASCIST` 枚举。

## 验收

- 正常立法结果显示总统弃牌、总理弃牌和总理颁布牌。
- 否决成功显示总统弃牌、总理两张弃牌和“总理未颁布政策”。
- 否决请求、否决被拒不会提前或重复写入结果记录。
- 终局结果包含已完成的立法记录；进行中的公共快照不包含该字段。
- 旧记录兼容、命令幂等重试、结果页映射和 UI 结构测试通过。

## 决策

本需求不引入新集合或长期不可逆技术取舍；实现已于 2026-07-29 完成，并同步 `api.md`、`architecture.md`、`product.md`。
