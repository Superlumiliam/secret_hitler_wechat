# RFC-0007：多人对局个人统计

## 目标

在 `user_profiles` 中持久化多人模式的完成对局数、胜局数和败局数；本期只做后端记录，不提供前端展示或客户端 DTO。

## 背景与证据

当前正常终局统一由 `gameService` 在事务中写入 `game_core`、结果投影和结束房间，终局时能够取得房间模式、最终胜方、冻结玩家名单和身份阵营。中断房间进入 `expired`，不会进入正常终局。结果数据只短期保留，因此旧资料只补默认值 `0`，不追溯既往战绩。

## 方案

- `user_profiles` 新增 `multiplayerGameCount`、`multiplayerWinCount`、`multiplayerLossCount`，新资料初始化为 `0`。
- 普通多人房间进入合法终局时，在同一事务内按最终阵营为真实玩家累计一次；观战者、虚拟席位和单人房间不累计。
- 玩家中途离线不改变其冻结玩家身份；若本局最终正常结束，仍记录胜负。
- 维护链路分页扫描旧资料，只给缺失字段补 `0`，以 `maintenance_state` 保存迁移进度并支持重复执行。

## 边界

- 包含：普通多人正常终局、旧资料补零、新资料默认值、迁移和幂等测试。
- 不包含：历史战绩追溯、逐局永久档案、排行榜、前端页面或客户端查询接口。
- 必须保持的不变量：`multiplayerGameCount = multiplayerWinCount + multiplayerLossCount`；一次终局对每名真实玩家最多累计一次。

## 接口与兼容性

无客户端 action、DTO、枚举或错误码变化。旧客户端不读取新增内部字段，不受影响。

## 失败场景与安全

统计更新与终局写入共用事务，命令幂等和房间终局状态防止重复累计。资料字段缺失按 `0` 计算；异常缺失整个资料文档时跳过该玩家并记录诊断，不阻断对局终局。迁移只补缺失字段，不覆盖已有统计。

## 验收

- [x] 普通多人正常终局按阵营累计对局、胜局和败局。
- [x] 单人、观战、虚拟席位和未完成对局不累计。
- [x] 离线真实玩家在正常终局后仍累计。
- [x] 重复终局命令不重复累计。
- [x] 旧资料补零迁移可续跑且可重复执行。
- [x] 后端自动化测试覆盖统计、迁移和新资料默认值。
- [x] 同步更新产品、架构和路线图；API 与游戏规则无变化。

## 决策

需求于 2026-07-30 确认并完成实现；旧资料只补 `0`，不追溯历史战绩。该方案不需要 ADR。
