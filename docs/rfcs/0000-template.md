# RFC-0000：标题

## 目标

用一段话说明要解决的问题、目标用户和可验证结果。

## 背景与证据

说明当前行为、问题证据，以及为什么现在需要处理。链接到相关产品、规则、API、架构、日志或测试。

## 方案

描述用户行为、关键数据流、接口变化和迁移方式。只写本需求需要的设计，不复制整份权威文档。

## 失败场景与安全

覆盖鉴权、并发、幂等、版本冲突、隐私、异常恢复、资源成本和回滚。
