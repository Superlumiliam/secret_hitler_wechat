# RFC-0009：多人对局阵营胜场统计

## 目标

在 `user_profiles` 中补充玩家作为自由派阵营或极权派阵营获胜的多人对局场次；本期只做后端记录和旧资料迁移，不提供前端展示或客户端 DTO。

## 方案

- 新增 `liberalWinCount`、`fascistWinCount`，新资料初始化为 `0`。
- 终局事件冻结每位真实玩家的阵营和是否获胜；维护消费事件时，只给获胜玩家递增其所属阵营的胜场字段。
- 单人、观战、虚拟席位和未完成对局不产生统计。
- 发布期间由一次性维护任务分页扫描旧 `user_profiles`，只补缺失字段 `0`，用独立的 `maintenance_state` 进度文档续跑；迁移完成后移除扫描代码，保留状态文档作为审计记录。
- 迁移每个资料时在事务内重读并只更新仍缺失的字段，避免覆盖并发统计写入。

## 边界与兼容性

不追溯历史对局；无客户端 action、DTO、枚举或错误码变化。终局事务不读取或直接更新用户资料，统计事件消费失败不影响结果页。

## 验收

- [x] 新资料包含两个阵营胜场字段。
- [x] 正常多人终局按玩家阵营累计对应胜场，重复事件最多累计一次。
- [x] 旧资料迁移可分页续跑、幂等且不覆盖已有值。
- [x] 迁移与统计并发时不把已累计值覆盖为 `0`。

## 决策

方案于 2026-08-04 实现并完成旧资料迁移。终局继续沿用 RFC-0008 的异步事件边界，避免统计写入故障阻塞对局进入结果页；一次性迁移代码已从常规定时维护中移除。
