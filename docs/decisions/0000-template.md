# ADR-0000：决策标题

## 上下文

说明需要长期决策的问题、约束和证据。普通局部实现细节不应创建 ADR。

## 决策

用明确陈述记录选择、适用边界和必须保持的不变量。

## 备选方案

简要列出认真考虑过的方案及未采用原因。

## 后果

记录收益、代价、风险、运维影响、兼容要求和未来撤销条件。

## 落地与验证

列出受影响的代码、测试、配置和权威文档。ADR 批准后，当前产品、API 和架构仍必须在同一次实现变更中更新；ADR 不能替代现行契约。
